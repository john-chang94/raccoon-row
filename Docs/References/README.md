# Raccoon Row design references

- [Final game vision and vertical slice](Dumpster%20Dynasty%20Game%20Vision%20and%20Vertical%20Slice.docx): the original finalized brief. It retains the former project title; Raccoon Row is the current name.
- [Game States](Mockups/Game%20States): courtyard/building, build placement, collection, crew/daily life, gate/scavenging, return, and active scavenging.
- [Asset Sheets](Mockups/Asset%20Sheets): UI, icons/items, buildings, courtyard, and Scout poses. Use the revised **Flat Gate** sheet for the gate; the earlier courtyard sheet remains for context.
- [First Visit Concepts](Mockups/First%20Visit%20Concepts): early and later courtyard progression and the Nest upgrade.

For active trips, prefer **07 Active Scavenging** for the in-yard timer. **05 Gate and Scavenging** is a departure/return reference, not approval for a separate active-trip screen. Illustrations and placeholder values are references, not production art or locked gameplay. The canonical raccoon art remains the approved CardArt thumbnail PNGs. This directory is outside Unity’s Assets folder.
